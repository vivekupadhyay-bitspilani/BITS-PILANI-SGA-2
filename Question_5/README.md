# Question 5: Evaluation of `vi`/`vim` Recovery Mechanisms and Crash Recovery Strategy

## Overview
This solution evaluates the crash recovery mechanisms available in the `vi`/`vim` text editor following an unsaved system crash while editing a critical configuration file.
